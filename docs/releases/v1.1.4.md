# 拾影 1.1.4

原生 macOS 视频下载器，支持 Bilibili、YouTube 和 yt-dlp 支持的其他网站。

## 下载和安装

- 下载 **PickVideo-v1.1.4-macos-arm64.dmg**，打开后将“拾影”拖到 Applications。
- ZIP 提供相同应用，SHA256SUMS.txt 提供文件校验值。
- 支持 **Apple Silicon、macOS 14+**，不提供 Intel 或 Windows 版本。
- 需要本机安装 **FFmpeg、Node、aria2**，可通过 `brew install ffmpeg node aria2` 安装。
- 当前包使用 ad-hoc 签名，**尚未获得 Apple Developer ID 签名和 Apple 公证**，首次打开可能需要按系统提示确认。

完整步骤见 [安装说明](https://github.com/XuanLIN0224/PickVideo/blob/main/docs/INSTALL.zh-CN.md)。

## 这个版本包含什么

- 修复 Bilibili 分离音视频合并时的同步错误，保留来源时间轴中的相对起始时间，不重新编码。
- 分别显示 Bilibili 普通高清、高码率及高帧率档位，展示来源实际帧率和含音轨的预计总大小。
- 支持应用内 Bilibili 扫码登录和当前会员状态核验。
- 对普通 Bilibili 视频优先使用官方元数据接口，减少网页超时造成的解析失败。
- 支持多连接加速、暂停和继续下载、视频与音轨合并及可选字幕保存。

画质、速度和网站支持仍受来源、账号权限、网络及解析引擎版本影响。此版本固定包含 yt-dlp 2026.08.19，可在设置中更新官方解析引擎。

## 验证

发布流程运行 38 项核心检查、13 项扫码登录回归、登录凭据生命周期检查、15 项 Bilibili 适配器检查和 7 项实际 FFmpeg 同步回归，然后检查签名完整性、安装包版本及架构。同步回归逐包验证时间关系和媒体数据，覆盖 MP4、MKV 及后续封装转换。

账号、Cookie、用户下载文件、个人下载历史和本地测试目录均不包含在源码或安装包中。请仅下载你有权保存的内容。
